# Multi-Stage Diabetic Retinopathy Severity Detection Using Retinal Features

An AI-based diabetic retinopathy severity detection system that analyzes retinal fundus images using image processing, retinal feature extraction, and deep learning techniques. The system uses a trained deep learning model to classify the severity of diabetic retinopathy through a multi-stage detection pipeline and provides prediction results through a Flask web interface.

## Features

- Upload retinal fundus images
- Image preprocessing
- Retinal feature extraction
- Deep learning-based severity prediction
- Automated diabetic retinopathy classification
- Flask-based web interface
- Pre-trained PyTorch model
- APTOS retinal image dataset
- Large files managed using Git LFS

## Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/Adhiyamaan09/multi-stage-diabetic-retinopathy-severity-detection-using-retinal-features.git
cd multi-stage-diabetic-retinopathy-severity-detection-using-retinal-features
```

### 2. Install Git LFS

This repository contains large files such as the trained deep learning model and retinal images. Git LFS is used to manage these files.

Install Git LFS if it is not already installed:

```bash
git lfs install
```

After cloning the repository, download the large LFS files:

```bash
git lfs pull
```

### 3. Create a Virtual Environment

For Windows:

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

Install all required Python packages:

```bash
pip install -r requirements.txt
```

## Running the Application

Activate the virtual environment:

```bash
venv\Scripts\activate
```

Start the Flask application:

```bash
python app.py
```

The Flask application will start locally.

Open the URL displayed in the terminal in a web browser.

For example:

```text
http://127.0.0.1:5000
```

## Troubleshooting

### Flask Application Not Starting

Make sure the virtual environment is activated:

```bash
venv\Scripts\activate
```

Then install the dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```

### PyTorch Import Error

Check whether PyTorch is installed:

```bash
python -c "import torch; print(torch.__version__)"
```

Check TorchVision:

```bash
python -c "import torchvision; print(torchvision.__version__)"
```

If the packages are missing, run:

```bash
pip install torch torchvision
```

### Model File Not Found

Make sure Git LFS files have been downloaded:

```bash
git lfs pull
```

Verify that the model exists:

```text
model/ConvNet_model.pt
```

### Dataset Images Not Available

Run:

```bash
git lfs pull
```

The dataset should be available at:

```text
python_scripts/APTOS Dataset/train_images/
```

### Dependency Installation Error

Make sure you are using the project's virtual environment:

```bash
venv\Scripts\activate
```

Then run:

```bash
pip install -r requirements.txt
```
